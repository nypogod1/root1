# Сайт для Софии ❤️

## Как открыть
Просто открой `index.html` в браузере.

## Как бесплатно разместить на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи туда `index.html`, `style.css` и `script.js`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми **Save**.
7. Через некоторое время GitHub выдаст ссылку на сайт.

## Как изменить текст
Все надписи находятся в `index.html`.

## Как добавить фотографии
Можно добавить блоки `<img>` в HTML и стилизовать их в `style.css`.
